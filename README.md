# Portfolio Website

A modern and responsive personal portfolio website built using **React.js** and **Tailwind CSS** to showcase my education, skills, projects, internships, achievements, and certifications.

##  Features

- Responsive design for desktop, tablet, and mobile
- Modern UI with smooth scrolling
- About Me section
- Education Timeline
- Internship Experience
- Technical Skills
- Projects Showcase
- Achievements & Certifications
- Resume View & Download
- Contact Information
- Social Media Links
- Interactive Animations

## Tech Stack

- React.js
- Tailwind CSS
- JavaScript
- HTML5
- CSS3
- React Icons
- Framer Motion
- React Scroll

## Installation

Clone the repository

```bash
git clone https://github.com/bhargavibayar02/portfolio_bsbhargavi.git
```

Go to the project folder

```bash
cd portfolio_bsbhargavi
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm start
```

Open your browser and visit

```
http://localhost:3000
```

## Build for Production

```bash
npm run build
```
